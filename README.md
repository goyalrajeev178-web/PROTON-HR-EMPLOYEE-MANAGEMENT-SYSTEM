📌 About the Project

PROTON HR is a simple desktop-based Employee Management System developed using Java Swing and MySQL.

It provides an easy-to-use graphical interface to manage employee information and perform basic employee management operations.

This project demonstrates practical implementation of Java programming, GUI development, and MySQL database connectivity.

✨ Features
👤 Employee Information Management
➕ Add New Employee Records
✏️ Update Employee Details
🗑️ Delete Employee Records
📋 View Employee Information
🗄️ MySQL Database Connectivity
🖥️ Simple and User-Friendly GUI

⚙️ Installation & Setup
1. Clone the Repository
bash
git clone https://github.com/goyalrajeev178-web/PROTON-HR-EMPLOYEE-MANAGEMENT-SYSTEM.git

2. Open the Project

Open the cloned project in your preferred Java IDE:

NetBeans
IntelliJ IDEA
Eclipse
3. Configure MySQL
Install and start MySQL Server.
Create the required database.
Configure your database connection settings.
Keep your actual dp.properties file locally.
4. Run the Application

Build and run the project from your Java IDE.

🔒 Security
Database credentials are stored locally.
Sensitive configuration files are excluded using .gitignore.
A sample configuration file can be provided for setup guidance.

Never upload your actual database credentials to GitHub.
